#### 反省点
 - A問題

最初は、文字列を1文字ずつ見ながら、最後の文字以外の後ろに `"o"` を追加する形で書いた。

```python
S = input()

answer = []

for i in range(len(S)):
    if i != len(S) - 1:
        answer.append(S[i])
        answer.append("o")
    else:
        answer.append(S[i])

print(*answer, sep="")
```

ACはできたが、あとから復習すると join() を使えばかなり簡潔に書けることに気づいた。

```python
S = input()
print("o".join(S))
```

- B問題

コンテスト中は、商品の金額をいったん文字列として受け取り、先頭の数字を使って「支払う金額」を作る方法で解いた。

```python
n = int(input())
A = list(map(str, input().split()))

coin1, coin10, coin100 = 0, 0, 0
calc = 0

for i in range(n):
    if A[i] != "1":
        calc = 1000 * (int(A[i][0]) + 1) - int(A[i])
    else:
        calc = 999

    coin1 += calc % 10
    coin10 += calc % 100 // 10
    coin100 += (calc % 1000) // 100

print(coin1, coin10, coin100)
```

あとから見ると、もっとシンプルに考えたり書いたりする方法はあったみたい。
ただ、今の自分としてはB問題も自分で考えてACまで持っていけたのは良かった。
無理に最短コードを目指すより、今は

自分で考える
→ ACする
→ あとから「もっといい書き方もあったな」と知る

くらいで進めていきたい。

### ホームページ（Ten-Homepage）のコード理解

#### `PROFILE` からHTMLに表示されるまで

`content.py` の `PROFILE` は、プロフィール情報を入れた辞書。

```python
PROFILE = {
  "title": "点のホームページ",
}
```

`app.py` の `home()` で、`PROFILE` を `profile` という名前で `index.html` に渡している。

```python
render_template(
  "index.html",
  profile=PROFILE,
)
```

HTMLの `{{ profile.title }}` は、Pythonの次の処理に近い。

```python
PROFILE["title"]
```

データが表示されるまでの流れは次の通り。

```text
content.py の PROFILE
↓
home() で profile という名前にして index.html へ渡す
↓
{{ profile.title }} で表示する
```

`PROFILE` と `profile` は別の名前。
大文字の `PROFILE` はPython側のデータで、小文字の `profile` はテンプレート側で使う名前。

#### ABC062_A

状態：解説AC

- `if` 式の評価順につまずいた
- `(x and y) in (l1 or l2)` は「`y` が `l1` にあるか」だけを判定する
- 想定の通り動かすには、次のように書く

```python
if (x in l1 and y in l1) or (x in l2 and y in l2):
  pass
```

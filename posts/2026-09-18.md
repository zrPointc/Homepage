### ABC123Aの復習

#### 問題のポイント
- 5つのアンテナの長さを入力する
- 1本目と5本目の差が、最後の条件と比べられる
- 条件に合うかどうかを判定する

#### 重要な考え方
- 配列の要素には順番がある
- 0番目から順に読み取る
- `l[0]` は最初の値
- `l[4]` は5本目の値
- `l[5]` は6本目の値（問題の条件で使う最後の値）

#### 間違えやすいコード
```python
l = []
for i in range(6):
    l[i].append(int(input()))
```

#### なぜダメか
- `l = []` で最初は空のリスト
- `l[i]` はまだ存在しない
- `append` は「リストに値を追加する」ためのメソッド
- なので `l.append(...)` の形にしないといけない

#### 正しい書き方
```python
l = []
for _ in range(6):
    l.append(int(input()))
```

#### 判定部分
```python
if l[4] - l[0] > l[5]:
    print(":(")
else:
    print("Yay!")
```

#### ここでの意味
- `l[4] - l[0]` : 5本目と1本目の差
- `l[5]` : 閾値
- 差が閾値より大きければ `:(`
- それ以外なら `Yay!`

#### まとめ
- リストの空っぽ状態で `l[i]` を使うと失敗する
- `append` で値を入れてから、インデックスでアクセスする
- Python では「追加」と「アクセス」を分けて考えるのが大事

### ABC093Bの復習

#### メモ：境界値「a+k」と「b+1-k」の計算理由】

 ・i < a+k （左端から K 個）
   - 左端 a から K 個目の数は「 a + (k - 1) 」になる。
  - つまり、その次の数である「 a + k 」未満（ < ）の整数が条件を満たす。
   - 例：a=10, k=3 のとき a+k=13 となり、13未満（10, 11, 12）の3個が選ばれる。
 
 ・i >= b+1-k （右端から K 個）
   - 右端 b から左へ K 個数えたときの、一番左端にある数は「 b - (k - 1) 」。
   - 括弧を外して整理すると「 b + 1 - k 」になる（カウントを調整する +1 ）。
   - つまり、この数以上（ >= ）の整数が条件を満たす。
   - 例：b=20, k=3 のとき b+1-k=18 となり、18以上（18, 19, 20）の3個が選ばれる。

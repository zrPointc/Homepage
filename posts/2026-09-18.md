### ABC123Aの復習

#### 問題のポイント
- 5つのアンテナの長さを入力する
- 1本目と5本目の差が、最後の条件と比べられる
- 条件に合うかどうかを判定する

#### 重要な考え方
- 配列の要素には順番がある
- 0番目から順に読み取る
- `l[0]` は最初の値
- `l[4]` は5本目の値
- `l[5]` は6本目の値（問題の条件で使う最後の値）

#### 間違えやすいコード
```python
l = []
for i in range(6):
    l[i].append(int(input()))
```

#### なぜダメか
- `l = []` で最初は空のリスト
- `l[i]` はまだ存在しない
- `append` は「リストに値を追加する」ためのメソッド
- なので `l.append(...)` の形にしないといけない

#### 正しい書き方
```python
l = []
for _ in range(6):
    l.append(int(input()))
```

#### 判定部分
```python
if l[4] - l[0] > l[5]:
    print(":(")
else:
    print("Yay!")
```

#### ここでの意味
- `l[4] - l[0]` : 5本目と1本目の差
- `l[5]` : 閾値
- 差が閾値より大きければ `:(`
- それ以外なら `Yay!`

#### まとめ
- リストの空っぽ状態で `l[i]` を使うと失敗する
- `append` で値を入れてから、インデックスでアクセスする
- Python では「追加」と「アクセス」を分けて考えるのが大事

#### 学び
- `list` は最初から埋まっている前提で使うとミスが出やすい
- `append` と `l[i]` の違いを理解することが重要
- 問題文の条件と配列の位置を対応させて読む練習が必要

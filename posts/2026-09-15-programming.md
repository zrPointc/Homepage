## 今日やったこと

### 自動集計ソフトの制作

途中で、どの入力画面でも「qを入力したら終了できるようにしたい」と思った。

最初は、それぞれの入力部分にこういう処理を書けばいいと思った。

```python
if value == "q":
    print("終了します")
    sys.exit()
```

でも、同じ処理を何回も書くことになる。
そこで、
「これ、毎回同じことをしているなら関数にまとめられるのでは？」
という話になった。

```python
def ask(prompt):
    value = input(prompt)

    if value.lower() == "q":
        print("終了します")
        sys.exit()

    return value
```

こうしておけば、

```python
group_column = ask("何の列ごとに集計しますか？: ")
value_column = ask("どの列を集計しますか？: ")
method = ask("集計方法を選んでください: ")
```

のように使える。

#### 今日の気づき
今までは「関数を書く」というと、
何か大きな処理を作るものだと思っていた。
でも今回、同じ処理が何度も出てきたら、
それを関数にまとめるという使い方があることが分かった。
最初からきれいなコードを思いつくというより、

1. まず動くコードを書く
2. 同じ処理が繰り返されていることに気づく
3. 共通部分を関数にする

という流れでもいいらしい。
今回は、自分から
「同じ処理を何度も書いていて、もっときれいに書けないのか」
と疑問に思えた。
